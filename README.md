# 🎉 Streamlit Wisher App

A beautiful animated wishing app built using Streamlit.

## Features

- Generate shareable wish links
- Animated greeting cards
- Birthday wishes
- Anniversary wishes
- Graduation wishes
- Congratulations wishes
- New Year wishes
- Custom messages
- Responsive UI
- Glassmorphism design
